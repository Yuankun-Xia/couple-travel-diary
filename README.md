# 慢慢走

静态只读旅行手帖。所有旅行文字、页面内容与照片在本地通过 AES-256-GCM 加密；此目录仅包含查看程序、字体和加密文件。

普通网址只显示入口。持有专属链接的人在浏览器中解密，不需要登录。链接密钥不在本仓库中。请勿提交原始 HTML、照片、备份、密钥或完整分享链接。

网站不含第三方脚本、统计或远程字体。GitHub Pages 发布来源为 `main` 分支根目录。只有仓库所有者通过 GitHub 认证后可以更新发布文件。浏览端不提供上传与修改接口。

完整链接相当于访问钥匙；任何持有人都能读取、保存、截图或转发内容。加密不能防止网站程序被篡改、设备入侵及解密后的复制。公开文件仍泄露大致体积、数量、提交时间，托管方也可能记录访问 IP。更换密钥不能追回已下载的旧内容或 Git 历史。
